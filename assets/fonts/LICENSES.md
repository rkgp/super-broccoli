# Font licences

All fonts in this folder are self-hosted copies (Latin subset, WOFF2) taken from the
Fontsource npm packages. Each is licensed under the SIL Open Font License 1.1, which
allows bundling and self-hosting.

| File | Family | Source package |
|---|---|---|
| inter-400.woff2, inter-500.woff2 | Inter | @fontsource/inter |
| source-serif-4-500.woff2 | Source Serif 4 | @fontsource/source-serif-4 |
| ibm-plex-mono-400.woff2, ibm-plex-mono-500.woff2 | IBM Plex Mono | @fontsource/ibm-plex-mono |
| bodoni-moda-500.woff2 | Bodoni Moda | @fontsource/bodoni-moda |

Self-hosting means visitors' browsers do not contact Google Fonts.
